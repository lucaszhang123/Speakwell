# Speakwell

Speakwell is a public-speaking practice app that helps users improve both delivery and content. Users choose a prompt, record a short response, review the transcript, and receive feedback on speaking habits and the organization of their ideas.

## Features

- Random public-speaking prompts
- Timed microphone recording
- Downloadable audio recordings
- Browser-generated transcript that users can edit
- Speaking feedback based on pace, vocal variation, volume, pauses, filler words, and repeated words
- AI content feedback based on logical clarity, organization, and relevance to the prompt
- Responsive interface for desktop and mobile browsers

## Requirements

- Node.js 20 or newer
- A modern browser such as Chrome or Edge
- Microphone access
- An OpenAI API key for AI content feedback
